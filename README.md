# TicketWay

TicketWay — навчальний DevOps-проєкт системи бронювання квитків на події, кіно та концерти.

## Мета проєкту

Метою є створення прототипу системи бронювання квитків із підтримкою CI/CD, контейнеризації, тестування та автоматизованого розгортання.

## Основні можливості

- перегляд доступних подій;
- вибір місць;
- бронювання квитків;
- обробка оплати;
- підтвердження бронювання;
- захист від повторного створення квитка;
- перевірка статусу оплати;
- автоматизоване тестування та розгортання.

## Архітектура

Проєкт складається з таких основних компонентів:

- `frontend` — клієнтська частина системи;
- `backend` — API та бізнес-логіка;
- `worker` — фонові задачі;
- `tests` — автоматизовані тести;
- `infra` — інфраструктурні конфігурації;
- `docs` — документація.

Для зберігання даних планується використання PostgreSQL.

## CI/CD

У проєкті використовується GitHub Actions.

Реалізовано:

- тестування коду;
- lint-перевірку;
- збірку Docker-образу;
- публікацію образу в GitHub Container Registry;
- staging deployment;
- production deployment;
- matrix build;
- reusable workflow;
- conditional jobs.

## Гілки

- `main` — основна гілка;
- `develop` — гілка для розробки.
